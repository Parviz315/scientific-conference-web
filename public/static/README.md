## Обоснование выбора ванильного JavaScript вместо React или Vue

В информационной системе «Ташкили Конфронсии илмӣ» страницы формируются на стороне сервера (PHP), а клиентская интерактивность носит точечный характер: валидация формы подачи доклада, живой поиск статей с задержкой и модальное подтверждение удаления. Весь клиентский сценарий занимает около 250 строк чистого ES-модуля без внешних зависимостей, кроме уже подключённого Bootstrap 5.3. Использование React или Vue потребовало бы установки Node.js, настройки сборщика (Vite), перехода на полноценный REST API и дублирования логики маршрутизации. Для приложения с формами и таблицами, разрабатываемого одним студентом, ванильный JavaScript с принципом прогрессивного улучшения проще в поддержке и не усложняет инфраструктуру проекта.
